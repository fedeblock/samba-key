# Security

Samba Key is experimental software and has **not been independently audited**. Do not deploy it on a public network; see the [installation guide](docs/INSTALL.md) and the [operations guide](docs/OPERATIONS.md) for the intended setup and its limits.

## Reporting a vulnerability

Please report security problems **privately**, using GitHub's private vulnerability reporting (the *Security* tab of the repository, then *Report a vulnerability*). Do not post credentials, tokens, logs with personal data or exploit details in a public issue.

Include what you found, how to reproduce it with a disposable account, and the version or commit you tested. This is a personal project maintained on a best-effort basis: there is no guaranteed response time or bounty.
